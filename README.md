# OffTheBall · 오프더볼

축구 영상 분석 프로그램의 첫 구현입니다. 현재는 사람 탐지 기준 기능과 정지 장면의 수동 거리 보정 실험을 제공합니다.

## 실행

이 PC는 설치와 모델 준비를 완료했습니다.

1. 프로젝트 폴더의 **실행.cmd**를 더블클릭합니다.
2. **영상 파일 선택**으로 MP4, AVI 등 영상을 엽니다.
3. **영상 분석 시작**을 누릅니다. 첫 모델 실행은 준비 시간이 걸릴 수 있습니다.
4. 결과는 **결과 폴더 열기**에서 확인합니다.

태블릿으로 노트북 화면을 촬영하려면 IP Webcam을 실행한 뒤 **태블릿 카메라 연결**을 누릅니다. 기본 주소는 `http://10.50.75.89:8080`이며, IP Webcam 페이지 주소를 입력하면 표준 `/video` MJPEG 스트림으로 연결합니다. 스트림은 로컬 PC가 직접 읽고, 외부에 카메라를 공개하거나 영상을 계속 저장하지 않습니다.

분석 창은 입력 영상의 재생 속도와 무관하게 처리되는 최신 결과를 보여줍니다. 파일 분석의 모든 프레임은 결과 영상에 저장되며, 화면 미리보기는 처리 속도에 따라 일부 프레임을 건너뜁니다.

## 현재 가능한 기능

- 로컬 영상 사람 탐지와 박스 표시
- 분석 중지 및 처리된 부분까지 저장
- 사용자가 지정한 화면 영역의 반복 캡처와 탐지 미리보기
- IP Webcam 태블릿의 실시간 MJPEG 수신·최신 프레임 탐지 미리보기
- 정지 장면의 경기장 기준점 수동 보정
- 보정 영역 안 두 지점의 미터 단위 추정 거리 측정
- 장면 이미지와 해당 장면의 보정 정보 저장

탐지 대상은 일반적인 사람입니다. 아직 선수/심판/관중 구분, 팀 분류, 선수 추적을 제공하지 않습니다.

## 정지 장면 거리 측정

1. 영상을 열거나 분석을 중지합니다.
2. **현재 장면 거리 보정**을 누릅니다.
3. 위치를 알고 있는 경기장 지점 4개 이상을 넓게 골라 클릭합니다.
4. 각 지점의 실제 X,Y 좌표를 미터로 입력합니다. 원점과 축 방향은 모든 점에서 같아야 합니다.
5. **보정 계산**을 누릅니다.
6. 기준점이 둘러싼 영역 안에서 두 지점을 클릭합니다.
7. 필요하면 **보정·장면 저장**을 누릅니다.

실제 좌표를 모르는 지점에 임의의 좌표를 넣으면 올바른 거리를 얻을 수 없습니다. 같은 직선 위에 몰린 기준점, 중복 좌표 등은 거부합니다. 기준점 바깥은 측정하지 않습니다.

보정은 현재 정지 이미지에만 유효합니다. 움직이는 영상에 재사용하지 않습니다. 수학적 변환 동작은 검증했으나 실제 경기 영상의 미터 단위 정확도는 아직 검증하지 않았습니다. 저장된 보정을 다시 여는 UI는 후속 작업입니다.

## 화면 영역 분석

- **화면 영역 분석**을 누르고 왼쪽, 위쪽, 너비, 높이를 정수로 입력합니다.
- 화면 경계를 벗어나는 영역은 거부합니다.
- 분석 창을 캡처 영역 밖에 배치하세요. 겹치면 자신의 결과 화면이 반복 캡처됩니다.
- **분석 중지**로 끝냅니다.
- 화면 모드는 미리보기만 제공합니다. 영상 녹화는 하지 않습니다.
- 실제 중계 서비스 캡처 성공 여부, 정지 화면 판별, 10분 연속 안정성은 미검증입니다.
- 검은 화면이 나타나면 입력을 확인해야 합니다.

## 태블릿 카메라 분석

- 태블릿의 IP Webcam 앱에서 서버를 시작하고 노트북과 같은 로컬 네트워크에 연결합니다.
- **태블릿 카메라 연결**을 누르고 IP Webcam 페이지 주소를 입력합니다. 기본값은 `http://10.50.75.89:8080`입니다.
- 앱의 페이지 주소는 표준 `http://호스트:포트/video` 스트림으로 해석합니다. `/video`를 직접 입력해도 됩니다.
- 네트워크 수신은 최신 프레임 한 개만 유지하므로 탐지가 늦어지면 오래된 프레임을 버립니다. 중지, 연결 종료, 읽기 시간 초과 때 이전 화면과 탐지 결과를 지웁니다.
- 미리보기의 처리 시간은 PC의 수신·디코드 이후 처리 시간입니다. 태블릿 카메라의 촬영 시각이나 종단 간 지연을 의미하지 않습니다.
- 이 기능은 네트워크 스트림을 분석용으로만 읽으며 원본 영상을 계속 녹화하지 않습니다.

## 결과 파일

각 실행마다 outputs 아래에 새 폴더를 만듭니다.

- analysis.mp4: 박스가 표시된 영상. 오디오는 포함하지 않습니다.
- frames.jsonl: 프레임별 시각·사람 박스·처리 시간. 미측정 팀/좌표는 null입니다.
- summary.json: 완료/중지/실패 상태와 처리 속도
- calibration.json, frame.png: 정지 장면 보정 저장 시 생성

결과 MP4는 원본의 명목 FPS로 저장됩니다. 가변 프레임률 영상의 정확한 재생 시간 보존은 아직 지원하지 않습니다. 원본의 프레임별 시각은 JSONL에 별도로 남깁니다. 홀수 영상 크기는 오른쪽/아래에 최대 1픽셀을 추가해 저장하고, 도중에 해상도가 바뀌면 중단합니다.

outputs에 있는 초기 검증 영상은 일반 인물 예제를 반복한 시험 입력의 결과입니다. 축구 분석 정확도의 증거가 아닙니다.

## 개발 환경 재설치

- 현재 검증 환경: Windows, Python 3.13.7, Intel Core Ultra 5 226V, Intel Arc 130V, RAM 약 15.5GiB.
- 현재 추론은 CPU를 사용합니다.
- Python 3.13과 uv가 준비된 환경에서 **설치.cmd**를 실행합니다.
- 의존성은 requirements.lock.txt에 고정했습니다.
- 첫 설치와 모델 다운로드에는 인터넷이 필요합니다. 기본 분석에는 API 키가 필요하지 않습니다.
- 모델 파일은 models/yolo11n.pt입니다.

개발용 실행:
~~~powershell
$env:PYTHONPATH = "$PWD\src"
.\.venv\Scripts\python.exe -m offtheball gui
.\.venv\Scripts\python.exe -m offtheball analyze "영상의 절대 경로.mp4"
.\.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider --basetemp=work\test-new-run
~~~

테스트 임시 폴더는 실행마다 새 이름을 사용하세요.
