### 발견한 문제
- Ultralytics(AGPL-3.0)가 이미 필수 의존성이다. MIT가 이를 없애지 않으므로 외부 배포·서비스 제공 전에 AGPL 의무를 검토해야 한다.
- `.gitignore`가 확장자 없는 `LICENSE`와 `pyproject.toml`을 무시해 Git에 올라가지 않고 있었다. 허용 목록에 추가했다.
- `gui_copy.py`는 `gui.py`의 복사본이고 참조가 없어 삭제했다.

### 열린 항목
- `LICENSE` 저작권자 표기(`OffTheBall contributors`) 확인
- Ultralytics AGPL 대응 방침 (외부 배포 전)
- 평가 클립(전술캠 2개 이상, 방송 1개 이상)과 100프레임 이상 수동 기준점 표기 (B2 전)
- GitHub 설정: 기본 브랜치 `develop`, squash 병합만 허용, 병합 후 브랜치 자동 삭제
- 로컬 생성물 삭제 범위 확정
