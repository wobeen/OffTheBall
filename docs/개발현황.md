## 완료 요약

### 구현 단위 1~4 — 자동 경기장 보정 기반 (2026-09-23, 커밋 완료)

1. **분석 계약과 보정 진단**: `contracts.py`에 탐지기·추적기·팀 분류기·보정기 구조적 인터페이스를 두고, 보정 출처·상태·age를 `calibration_diagnostics()`로 정규화했다. `frames.jsonl`과 `summary.json`에 `schema_version: 2`, `calibration_status`, `calibration`을 추가했다(기존 필드는 유지).
2. **키포인트 RANSAC 보정 후보**(`keypoint_calibration.py`): 경기장→영상 방향 RANSAC, inlier 재계산, 최소 점 수·분포·inlier 비율·재투영 오차·역행렬·지평선 검사, 검증된 키포인트 영역 밖은 `NaN`. 전술 보드가 비어 있을 때 `기준 보정 후 선수 위치가 표시됩니다`를 표시한다. 원인은 그라운드 영역(관중 제외용 픽셀 다각형)과 기준 보정(영상→미터)이 별개인데 보정을 안 한 입력이었다.
3. **기준 배치·보정 실행 수정과 도움말**: 분석 중에도 `기준 배치`·`기준 보정`을 쓸 수 있게 했다. 파일 분석 중 기준 보정은 자동 일시정지 후 현재 프레임으로 보정 창을 열고 저장하면 현재 세션에 적용한다(`playback.py`의 `_apply_playback_commands()`). 화면·태블릿·내보내기 중에는 중지 안내를 표시한다. 앱 내 도움말 추가.
4. **시간 안정화**(`calibration_state.py`): 후보를 채택·거부(공유점 중앙 투영 차이 기본 8m 초과 또는 공유점 4개 미만이면 거부)하고, 후보가 없으면 최대 30프레임 재사용한 뒤 `stale`로 바꿔 좌표를 `NaN`으로 막는다. stale 이후에는 새 장면 후보를 다시 채택한다. 8m·30프레임은 합성 검증용 초기값이며 실영상으로 조정해야 한다.

위 모듈은 아직 키포인트 모델이나 GUI에 연결하지 않았다. 실제 영상 정확도는 미검증이다(합성 대응점으로 수학적 동작만 확인).

### 버전 0.2 — 팀 분류와 추적

- 파일·화면·태블릿 입력이 모두 공식 ByteTrack 임시 ID, 팀 A/B 추정, 최근 15개 화면 궤적을 쓴다. `scene_id + track_id`를 함께 기록한다.
- 상의 Lab 색상으로 팀을 분류하고 작은·가려진·애매한 색상은 미분류로 둔다. 검은 입력, 시각 역전·긴 공백, 해상도 변화, 장면 전환에서 추적을 초기화한다(장면 전환에서는 유니폼 기준 유지).
- 팀 정확도 95%, ID 전환 횟수 같은 정량 목표는 통과했다고 주장하지 않는다. 빠른 움직임·가림·장면 전환에서 ID가 바뀔 수 있고 장면 감지는 휴리스틱이다.

### 버전 0.1.0 — 기반 (2026-09-15)

- Python 3.13 환경과 의존성 고정, YOLO11n 사람 탐지, 파일·화면 영역 입력, 결과 영상·프레임 데이터 저장, 중지·예외 시 부분 결과 저장, 수동 호모그래피, 한국어 Tkinter UI, IP Webcam MJPEG 입력(`/video`).
- 교체 영상 `manvsmci.mp4`(약 32.77초, 980프레임): 처리 약 105.34초(9.30fps), 검은 프레임 0개. 사람 탐지는 작동하나 정확도 수치와 거리 측정은 미검증이다.
- 태블릿 `http://10.50.75.89:8080/video`에서 1920×1080 JPEG를 실제로 디코드했다. 새 유효 프레임이 5초 이상 없으면 입력을 끊고 화면·탐지를 지우며 자동 재연결은 없다. 표시 시간은 PC 수신·디코드 이후 경과이며 종단 간 지연이 아니다.
- **쿠팡플레이 녹화·실시간 캡처가 검게 나오는 것은 DRM 캡처 차단이 원인**으로 확정했다(캡처 단계에서 차단). 우회하지 않으며 대체 입력(비보호 소스, HDMI 캡처보드 등)을 후속 과제로 둔다.

## 검증의 한계

- 자동 검증은 합성 영상, 모의 입력, 수학적 보정, 숨겨진 UI 동작 검사다.
- 축구 선수 탐지 정밀도·재현율, 실제 거리 오차, 팀 분류·추적 정량 성능은 미검증이다. 평가 클립과 수동 정답은 B2에서 만든다.
- 화면 캡처는 최신 프레임을 순차 처리한다. 캡처·추론 완전 분리, 입력 동결 감지, 장시간 안정성은 미검증이다.
- 기본 모델 입력은 960, CPU 4스레드다. Intel GPU 가속은 적용하지 않았다.
