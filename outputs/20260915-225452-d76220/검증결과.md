# 0.2 팀 분류·선수 추적 검증

## 완료
- 공식 BYTETracker 사용을 실제 모델 객체로 확인.
- 기존 경기 영상 전체 980프레임 처리, 결과 MP4 재디코딩 980프레임 확인.
- 팀 A/B/미확인, 임시 번호, 최근 15개 화면 좌표 궤적 표시.
- 프레임 데이터에 장면 번호와 추적 번호 저장.
- 모든 감지된 장면 전환의 첫 결과에서 이전 궤적이 비워졌는지 확인.
- 자동 테스트 54개 통과, 마지막 장면 비교 수정 후 관련 10개 통과.

## 실제 영상에서 보완한 점
초기 분류는 어두워진 하늘색 유니폼을 빨간 팀으로 잘못 분류했다.
상의 범위를 좁히고 밝기 영향을 줄였으며 가까운 두 후보는 미확인으로 남기도록 수정했다.
대표 넓은 장면에서는 두 유니폼 색상이 대체로 대응하며, 불확실한 클로즈업은 미확인으로 처리된다.
이 관찰은 수동 정답 데이터로 측정한 정밀도나 재현율이 아니다.

## 성능과 한계
전체 처리 약 237.67초, 약 4.12fps. 기존 파일 탐지만의 측정값과 입력 기능이 다르며 실시간 목표를 달성했다고 주장하지 않는다.
태블릿 입력은 최신 프레임만 처리하므로 지연 누적을 줄이지만 표시 갱신이 느릴 수 있다.
빠른 움직임·가림·작은 사람에서 추적 번호가 바뀔 수 있고 일부 중복 탐지도 남는다.
장면 전환 규칙은 모든 전환을 완벽하게 찾지 못한다.
궤적은 화면상 이동이며 카메라 이동이 포함된다. 실제 미터 거리/속도/포메이션 분석은 아직 없다.
팀·추적의 계획상 정량 정확도 목표는 아직 통과 처리하지 않았다.

## 사용
기존 창을 닫고 프로젝트의 실행.cmd를 다시 연다.
영상 분석 또는 태블릿 카메라 연결을 시작하면 새 기능이 적용된다.
A/B는 표시용 팀 이름이며 실제 팀명/등번호는 아니다.
